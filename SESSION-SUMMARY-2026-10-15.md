## 9 bugs found across the 4 doc-only ports (Python ref, JS, C#, Perl, C)

| # | Port | Bug | Fix |
|---|------|-----|-----|
| 1 | Perl | JSON::PP booleans are objects, not strings | `ref($v) eq 'JSON::PP::Boolean'` |
| 2 | Perl | `$$path[$idx]` doesn't compile in 5.36 | use `$path->[$idx]` |
| 3 | Perl | Wide char in sha256 with `use utf8` | `Encode::encode_utf8` |
| 4 | Perl | ARGV is bytes by default | `decode_utf8` on ARGV |
| 5 | Perl | JSON::PP `canonical(1)` is too compact | custom 30-line encoder |
| 6 | JS | `v.toString()` for floats gives `0.00001` for 1e-5 | custom `numFormat()` |
| 7 | C# | `GetRawText()` for `JsonValueKind.Number` returns raw | use `TryGetInt64 / NumFormat` |
| 8 | C# | Integers formatted as `1.0` via `F1` | `(long)v.ToString()` for integer floats |
| 9 | C | Heap-use-after-free in `closure_root` | copy strings before freeing array |

The C port's bug (#9) is the only one that wouldn't have been caught by per-port unit tests — it's specific to manual memory management.
